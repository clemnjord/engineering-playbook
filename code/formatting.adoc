= Code formatting

== TypeScript, JavaScript, and JSON

Use Prettier to format your code.

Install Prettier in a project by typing the following commands:
[source, shell]
----
npm install --save-dev --save-exact prettier
----

Add the following `.prettierrc` configuration file to the root of your project:
[source, json]
----
{
    "printWidth": 100,
    "tabWidth": 4,
    "semi": true,
    "singleQuote": true,
    "trailingComma": "all",
    "arrowParens": "always",
    "endOfLine": "lf"
}
----
